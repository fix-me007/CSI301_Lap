How it works

มั่นใจใน 3 ขั้นตอน

  1. 01
    กรอกรหัสใบรับรอง

    หรือเปิดลิงก์จาก QR Code

  2. 02
    คำนวณ Hash จาก PDF

    เลือกไฟล์ที่ต้องการตรวจ ใช้รหัสหลักสูตรและ salt เดิม

  3. 03
    รับผลจากบล็อกเชน

    ตรวจทั้ง Hash และการเพิกถอน

อ่านไฟล์ในเบราว์เซอร์ ไม่อัปโหลด PDF หรือข้อมูลส่วนบุคคลไปยัง server

เฉพาะ Admin เพิ่มหรือเปิด/ปิดหลักสูตรได้ · การปิดหลักสูตรไม่เพิกถอนใบรับรองที่ออกไปแล้ว

สำหรับ Issuer ที่ได้รับอนุญาตเท่านั้น · บันทึกเฉพาะรหัสหลักสูตร รหัสใบรับรอง Wallet และ Hash ไม่บันทึกชื่อผู้รับบนเชน

ออกใบรับรองใหม่

ตรวจสอบข้อมูลให้ครบก่อนยืนยัน รายการที่ออกแล้วแก้ไขไม่ได้

เลือก PDF ฉบับสมบูรณ์ที่มีชื่อและรายละเอียดผู้รับ แล้วสร้าง Hash ก่อนออกใบรับรอง · เก็บ PDF และ salt นอกเชน · วันที่ออกบนเชนบันทึกอัตโนมัติเมื่อธุรกรรมยืนยัน

ต้องเชื่อมต่อ Wallet ที่มีสิทธิ์ Issuer และมี Sepolia ETH สำหรับค่า gas · รหัสและ Hash ใช้ซ้ำไม่ได้

Off-chain hash studio

สร้าง Hash อย่างเป็นส่วนตัว

ตรวจเอกสารปลอมให้ Hash จากไฟล์ PDF จริง คำนวณในเบราว์เซอร์ ไม่ส่งไฟล์ ชื่อ หรือ salt ไปยัง RPC

สูงสุด 20 MiB · Hash ทุกไบต์ รวมชื่อ รายละเอียด และ metadata ภายใน PDF การบันทึกไฟล์ใหม่อาจเปลี่ยน Hash แม้หน้าตาเหมือนเดิม · ไม่อัปโหลดไฟล์

สูตรเดียวกับ computeHash ใน Solidity แต่ทำ off-chain ตรวจเฉพาะข้อมูล 4 ช่อง ไม่ยืนยันว่าไฟล์ PDF ไม่ถูกแก้ไข

เก็บ PDF ต้นฉบับ วิธี Hash รหัส และ salt อย่างปลอดภัย ต้องใช้ค่าเดิมเพื่อตรวจซ้ำ ปิดหน้าต่างแล้วข้อมูลจะถูกล้าง ไม่เก็บใน localStorage หรือบนเชน
